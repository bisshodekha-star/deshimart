# 🛒 দেশিমার্ট — অ্যাডভান্স ই-কমার্স ওয়েবসাইট

বাংলাদেশের জন্য তৈরি সম্পূর্ণ ই-কমার্স ওয়েবসাইট। কোনো কোডিং জানা লাগে না —
নিচের ধাপগুলো ধরে ধরে এগোলেই আপনার দোকান ইন্টারনেটে লাইভ হয়ে যাবে।

## ✅ এই ওয়েবসাইটে যা যা আছে

| ফিচার | বর্ণনা |
|---|---|
| 🏠 আধুনিক হোমপেজ | হিরো ব্যানার, ক্যাটাগরি, ফিচার্ড পণ্য, রিভিউ, ট্রাস্ট ব্যাজ |
| 🔍 শপ + সার্চ | বাংলা ও ইংরেজি — দুই ভাষাতেই পণ্য খোঁজা যায়, ক্যাটাগরি ফিল্টার, সর্টিং |
| 📦 পণ্য ডিটেইলস | ছবি, দাম, পুরনো দাম, রেটিং, স্টক, সম্পর্কিত পণ্য |
| 🛒 কার্ট + চেকআউট | ক্যাশ অন ডেলিভারি ও বিকাশ অপশন, ফোন ভ্যালিডেশন |
| 🚚 অর্ডার ট্র্যাকিং | কাস্টমার ফোন নম্বর দিয়ে নিজের অর্ডার দেখতে পারবে |
| 🔔 নোটিফিকেশন বেল | নতুন অর্ডার আসলে অ্যাডমিন সাথে সাথে জানতে পারবেন |
| 🤖 AI চ্যাট "মেঘ" | ২৪/৭ বাংলা AI সহকারী — লাইভ দাম দেখে প্রশ্নের উত্তর দেয় |

# 🚀 লাইভ করার ৩টি ধাপ (সময়: মাত্র ২০–৩০ মিনিট)

```
ধাপ ১: GitHub-এ কোড আপলোড        (৫ মিনিট)
ধাপ ২: Neon-এ ফ্রি ডাটাবেস খোলা    (৫ মিনিট)
ধাপ ৩: Vercel-এ কানেক্ট করে ডিপ্লয় (১০ মিনিট)
```

সব সার্ভিসই **ফ্রি**। শুধু একটি ব্রাউজার আর ইন্টারনেট লাগবে — কোনো সফটওয়্যার ইনস্টল করতে হবে না।

---

## ধাপ ১ — GitHub-এ কোড আপলোড

1. ব্রাউজারে যান: **https://github.com** → অ্যাকাউন্ট খুলুন (বা লগইন করুন)
2. ডান পাশে উপরে **`+`** আইকন → **New repository** ক্লিক করুন
3. Repository name দিন (যেমন: `my-shop`) → **Private** সিলেক্ট করুন → **Create repository**
4. এবার ZIP ফাইলটি আনজিপ (extract) করুন — ভেতরে **`deshimart`** ফোল্ডার পাবেন
5. `deshimart` ফোল্ডারটি **খুলুন** (ভেতরে ঢুকুন) — ভেতরে `src`, `public`, `package.json` ইত্যাদি দেখবেন
6. **সব ফাইল সিলেক্ট করুন** (Ctrl+A) → GitHub-এর নতুন রিপো পেজে **"uploading an existing file"** লিংকে ক্লিক → সব ফাইল **টেনে ছেড়ে দিন** (drag & drop)
7. নিচে **Commit changes** বাটনে ক্লিক করুন → আপলোড শেষ হওয়া পর্যন্ত অপেক্ষা করুন

> ⚠️ **গুরুত্বপূর্ণ:** আপলোড শেষে রিপোর হোম পেজে `package.json`, `src` ফোল্ডার, `.gitignore` — এগুলো দেখা যাচ্ছে কিনা নিশ্চিত করুন। `package.json` যদি না দেখা যায়, তাহলে ফোল্ডারের ভেতরের ফাইলগুলো আপলোড হয়নি — আবার চেষ্টা করুন।

---

## ধাপ ২ — Neon-এ ফ্রি ডাটাবেস খোলা

ওয়েবসাইটের সব তথ্য (পণ্য, অর্ডার) থাকবে এই ডাটাবেসে।

1. ব্রাউজারে যান: **https://neon.com** → **Sign Up** → **Continue with GitHub** দিয়ে ঢুকুন (পাসওয়ার্ড মনে রাখার ঝামেলা নেই)
2. প্রজেক্ট নাম দিন (যেমন: `my-shop`) → **Create project**
3. Region হিসেবে **Singapore** বা **Frankfurt** সিলেক্ট করলে বাংলাদেশ থেকে সাইট দ্রুত চলবে
4. প্রজেক্ট তৈরি হলে একটি **Connection String** দেখাবে — এরকম দেখতে:
   ```
   postgresql://neondb_owner:AbC123xyz@ep-cool-name-123456.aws.neon.tech/neondb?sslmode=require
   ```
5. **Copy** বাটনে ক্লিক করে এই লম্বা লাইনটি কপি করে রাখুন (নোটপ্যাডে পেস্ট করে রাখুন)

> 💡 এই স্ট্রিংটিই আপনার দোকানের "গুদামঘরের চাবি" — কারও সাথে শেয়ার করবেন না।

---

## ধাপ ৩ — Vercel-এ কানেক্ট করে লাইভ করা

1. ব্রাউজারে যান: **https://vercel.com** → **Sign Up** → **Continue with GitHub** (একই অ্যাকাউন্ট)
2. Vercel আপনার GitHub কানেক্ট করতে চাইলে **Authorize Vercel** দিন
3. ড্যাশবোর্ডে **Add New… → Project** ক্লিক করুন
4. আপনার `my-shop` রিপোর পাশে **Import** বাটনে ক্লিক করুন
5. **Configure Project** পেজে:
   - Framework Preset: **Next.js** (অটো সেট থাকবে) — ধুলে বাদ দিন
   - নিচে **Environment Variables** সেকশনে ৩টি ভ্যারিয়েবল যোগ করুন:

   | Name | Value |
   |---|---|
   | `DATABASE_URL` | ধাপ ২-এ কপি করা Neon কানেকশন স্ট্রিং |
   | `ADMIN_PASSWORD` | আপনার নিজের গোপন পাসওয়ার্ড (যেমন: `Rahim@2026#Shop`) |
   | `NEXT_PUBLIC_STORE_NAME` | আপনার দোকানের নাম (যেমন: `রাহাত স্টোর`) |

   > `NEXT_PUBLIC_STORE_TAGLINE` দিতে চাইলে দিন (যেমন: `ঘরে ঘরে বিশ্বস্ত সেবা`) — না দিলেও সমস্যা নেই।

6. **Deploy** বাটনে ক্লিক করুন → ২–৩ মিনিট অপেক্ষা করুন 🎉
7. সবুজ **"Congratulations!"** স্ক্রিন এলে আপনার সাইট লাইভ!
   ঠিকানা হবে: `https://my-shop-xxxx.vercel.app` — এই লিংক যে কাউকে দিলেই সে আপনার দোকান দেখতে পাবে

> ✅ **নিশ্চিন্ত থাকুন:** Vercel স্বয়ংক্রিয়ভাবে ডাটাবেসে টেবিল তৈরি করে নেয় (migration)। HTTPS/SSL সার্টিফিকেটও ফ্রি আর অটোমেটিক।

# 🧑‍💼 প্রথমবার দোকান চালু করা (পণ্য যোগ করা)

1. আপনার লাইভ সাইটে যান → উপরের মেনু থেকে **অ্যাডমিন** ক্লিক করুন
2. পাসওয়ার্ড দিন — এটিই Vercel-এ `ADMIN_PASSWORD` হিসেবে দেওয়া পাসওয়ার্ড
3. দোকান খালি থাকলে **"ডেমো পণ্য লোড করুন (২২টি)"** বাটন দেখবেন → ক্লিক করুন
   → সাথে সাথে ৬টি ক্যাটাগরি আর ২২টি ডেমো পণ্য চলে আসবে!
4. এবার নিজের পণ্য যোগ করুন:
   - **নতুন পণ্য** বাটন → নাম, দাম, বর্ণনা, স্টক লিখুন
   - ছবি: কোনো ছবির লিংক (URL) পেস্ট করুন। ফ্রি ছবি হোস্ট করতে **https://imgbb.com**-এ ছবি আপলোড করে লিংক কপি করুন
   - ডেমো পণ্যগুলো মুছে দিয়ে নিজের পণ্য বসান — ব্যস, দোকান আপনার!
5. অর্ডার এলে: অ্যাডমিন প্যানেলের **অর্ডার** ট্যাবে দেখবেন + উপরে বেলে 🔔 লাল ব্যাজ — ক্লিক করে স্ট্যাটাস আপডেট করুন (পেন্ডিং → কনফার্মড → শিপড → ডেলিভারড)

# 🔄 পরে কোনো কিছু বদলাতে চাইলে

| কী বদলাবেন | কীভাবে |
|---|---|
| দোকানের নাম | Vercel → Settings → Environment Variables → `NEXT_PUBLIC_STORE_NAME` বদলান → Deployments ট্যাব → সর্বশেষ ডিপ্লয়ের ⋯ → **Redeploy** |
| পণ্য/দাম/স্টক | লাগবেই না কোড — সব অ্যাডমিন প্যানেল থেকে করুন |
| পাসওয়ার্ড | Vercel → `ADMIN_PASSWORD` বদলান → Redeploy (পুরনো সেশন অটো বাতিল হবে) |

# 🌐 নিজের ডোমেইন যোগ করা (যেমন: myshop.com.bd)

*.vercel.app লিংক দিয়েই ব্যবসা চলে, কিন্তু নিজের ডোমেইন থাকলে আরও পেশাদার দেখায়:

1. ডোমেইন কিনুন: **Namecheap** (~১,৫০০৳/বছর) অথবা বাংলাদেশের **Hostever/Exabytes** (বিকাশে পেমেন্ট)
2. Vercel → আপনার প্রজেক্ট → **Settings → Domains** → ডোমেইন লিখে **Add**
3. ডোমেইন কোম্পানির সাইটে DNS সেটিংসে যেয়ে Vercel যে রেকর্ড দেখায় সেটি বসান (A Record: `76.76.21.21` বা CNAME: `cname.vercel-dns.com`)
4. কয়েক ঘণ্টার মধ্যে SSL সহ আপনার নিজের নামে সাইট লাইভ!

# 🧰 সমস্যা হলে (Troubleshooting)

| সমস্যা | সমাধান |
|---|---|
| Deploy ব্যর্থ — "Environment variable not found: DATABASE_URL" | ধাপ ৩-এর টেবিল অনুযায়ী `DATABASE_URL` ভ্যারিয়েবলটি ঠিকমতো দিন, তারপর Redeploy |
| সাইট খুললে "দোকান খালি" বা পণ্য লোড হয় না | অ্যাডমিন প্যানেলে লগইন করে ডেমো পণ্য লোড করুন; অথবা `DATABASE_URL` সঠিক কিনা দেখুন |
| অ্যাডমিন লগইন হয় না | `ADMIN_PASSWORD` যেটা দিয়েছেন সেটাই; না দিলে ডিফল্ট: `deshimart2026` |
| AI চ্যাট "ডেমো মোড" দেখাচ্ছে | AI সার্ভিসের কী (key) ছাড়া চ্যাট সীমিত মোডে চলে — সাইটের বাকি সব ফিচার স্বাভাবিক থাকে |
| ছবি দেখাচ্ছে না | ছবির লিংক `https://` দিয়ে শুরু হয়েছে কিনা দেখুন (imgbb.com ব্যবহার করুন) |

# 🏗️ প্রযুক্তি (ডেভেলপারদের জন্য)

- **Next.js 16** (App Router) + **TypeScript** + **Tailwind CSS 4** + **shadcn/ui**
- **Prisma ORM** + **PostgreSQL** (Neon) — `prisma/migrations` সহ, Vercel বিল্ডে অটো `migrate deploy`
- **z-ai-web-dev-sdk** — AI চ্যাট (কী ছাড়া graceful fallback)
- **Zustand** — কার্ট স্টেট (persist) · বাংলা সংখ্যা/৳ ফরম্যাটিং `src/lib/format.ts`

লোকালে চালাতে চাইলে:
```bash
cp .env.example .env   # .env-এ নিজের DATABASE_URL বসান
npm install
npm run dev            # http://localhost:3000
```

> লোকাল ডাটাবেসে ডেমো ডেটা ঢোকাতে: `DATABASE_URL=<আপনার url> bunx tsx prisma/seed.ts`
> (Vercel-এ লাগে না — অ্যাডমিন প্যানেলের বাটনেই সব হয়।)
